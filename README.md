
# pms-dxt (Deprecated)

⚠️ This project is now deprecated.
The recommended packaging format has moved from .dxt to .mcpb, and .dxt packages are no longer maintained.

👉 Use pms-mcpb instead.
pms-mcpb is the official toolchain for generating .mcpb packages for pty-mcp-server.

📦 pms-mcpb repository:
https://github.com/phoityne/pms-mcpb
